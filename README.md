# US Google Advertising Managers to Japan — Intercultural Training

Static HTML/CSS/JS slide deck and cited manager-training report.

## Contents

- `index.html` — interactive browser presentation with slides, citations, quiz, and sorting exercise.
- `report.pdf` — cited training report.
- `report.docx` / `report.md` — editable report versions.
- `assets/generated/` — KIE-generated visuals and manifest with prompts/model names.

## Deployment note

This repository commits the static artifact directly. Coolify can serve the repository root with:

- Build pack: static
- Base directory: `/`
- Publish directory: `/`
- Install/build commands: blank

## Brand note

The deck uses Google-color accents and plain-text Google references. It does not modify or embed the Google logo. The content follows the public Google Partner Marketing Hub rule that Google’s role must be presented accurately.
